# 运维中心开发清单

目标：实现运维功能；按用户后续要求撤掉账号系统，恢复仅口令登录与无固定期限的登录记忆，保留现有安全修复和硬件控制页。

用户明确要求保留原布局：不得改动原控制台的导航、卡片位置、颜色和布局样式。
新增功能位于独立的 `/manage.html`，复用原 `style.css` 的主题、字体和卡片样式；
不新增原控制台导航按钮，不采用侧栏布局。此约束优先于先前界面实现。

使用 Python 标准库、SQLite 和原生前端；数据写入应用 var 目录，敏感数据文件私有。
新自动策略默认关闭。备份不包含访问口令、访问密钥和通知凭据。

1. 配置备份：创建、下载、导入、差异预览、确认恢复。
2. 历史监控：后台采样、保留期限、区间查询、趋势图和 CSV 下载。
3. 外部告警：邮件 / Webhook 设置、去重队列、重试、投递记录。
4. 操作审计：时间、操作身份、来源、动作、结果，筛选和导出。
5. 周计划：每周日期、临时跳过、设备时区执行预览，RTC 与关机检查。
6. 健康报告：汇总状态和告警，可下载报告。
7. 故障诊断：检查传感器、服务、RTC 和配置，受控修复入口。
8. 风扇保护：超温 / 传感器失效时全速，恢复条件与原因记录。
9. 配置历史：保存版本、差异、回退。
10. 脚本保护：摘要与变化检查、执行确认、超时、取消、重复运行限制。
11. 维护模式：限时暂停计划与预期告警，到期恢复，保留风扇保护。
12. 已撤销账号角色功能：不需要账号，不创建账号管理入口；仅口令登录。
13. 自动化密钥：按权限签发、到期、撤销、只显示一次。
14. 多设备：显式登记地址和只读密钥，聚合状态 / 告警，跳转控制台。
15. 磁盘趋势：按稳定设备标识保存 SMART，显示增量与历史。

验收：功能测试、拒绝路径测试、浏览器实际交互、构建内容核对。
实机特有的 systemd / RTC / 风扇行为需单独标记验证边界，禁止用桩测试宣称真机通过。
