# 运维使用说明

入口为电脑顶部或手机底部的“运维”，也可访问 `http://设备地址:18899/manage.html`。仅需访问口令，登录记忆与控制台共用，无固定有效期。

运维只保留八项：备份与版本、计划与维护、风扇保护、告警推送、操作审计、访问密钥、多设备、脚本任务。原设备健康、历史监控与磁盘趋势页面不再提供，旧链接会回到当前有权限访问的页面。

| 页面 | 操作方式 |
| --- | --- |
| 备份与版本 | 输入备份说明并创建下载；导入不超过 64 KB 的 JSON，先查看差异再确认恢复。恢复前自动备份。下方配置版本可比较并回退。 |
| 计划与维护 | 勾选执行星期、填写跳过日期；开关机时间和总开关仍在概览页设置。维护最多 24 小时，到期自动恢复，也可提前结束。 |
| 风扇保护 | 设置 CPU / 硬盘阈值和连续异常次数。保护由设备服务执行；曲线和常规调速在控制页设置。 |
| 告警推送 | 选择 Webhook 或支持 STARTTLS 的邮件渠道，保存后仅推送新告警；投递失败最多重试 4 次。更换目标或账号时重新填写凭据。 |
| 操作审计 | 用身份、动作关键词筛选，支持回车查询、重置和 CSV 导出。一次查询最多 500 条，列表每页 10 条，导出包含当前查询的全部结果。 |
| 访问密钥 | 填写用途和有效天数，选择最小必要权限；创建后完整密钥只显示一次，可复制。撤销需确认并立即生效。 |
| 多设备 | 展开“添加设备”，填写目标控制台地址及其签发的只读密钥；查看在线状态、温度与告警。移除只影响本地登记，不修改目标设备。 |
| 脚本任务 | 按状态筛选、查看输出和取消运行中的任务。启动失败也会保留日志与退出码。脚本上传、管理、DTB 及灯光维护统一在控制页脚本库。取消不会撤销已经完成的系统改动。 |

## 操作反馈

保存期间按钮会禁用，避免重复提交。失败时保留输入并说明原因；计划应用失败时会恢复原规则，系统服务恢复失败会另行提示。读取失败时可以重新加载。快速切换页面不会被旧请求的结果覆盖。较长列表分页显示，手机端将每条记录的字段分行展示。

恢复、撤销密钥、移除设备和取消任务均需确认。脚本执行弹窗先显示操作影响，代码、差异和 SHA256 可展开查看；涉及系统改动时仍须输入 `yes`，执行时核对当前摘要。

## 权限与数据

口令登录可使用全部功能。未设置口令时，远程访问只读，对应保存控件不可用。API 密钥可分别授予 `read`、`control`、`scripts`、`admin` 权限，管理权限不自动包含其他权限。密钥有效期不影响网页口令登录记忆。

配置备份包含风扇、灯光、蜂鸣、计划及保护设置，不包含访问口令、密钥和通知凭据。备份恢复会保留当前的临时维护期限。

运维数据保存在应用 `var/operations/operations.sqlite3`，可通过 `S2_OPERATIONS_DIR` 指定独立目录。移除页面不会删除已有数据。升级、卸载和硬件维护的说明见 [原生硬件与 DTB](native-hardware.md)。

真实硬件操作依赖设备上的服务、驱动及 RTC 支持；界面验证通过不代表完成了 NAS 实机刷写或重启验证。
