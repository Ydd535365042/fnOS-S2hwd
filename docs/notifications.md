# 告警通知

告警记录继续显示在控制台右上角铃铛中。点击“邮件 / 推送设置”进入独立通知页面；这里保留邮件和 Webhook 配置、测试通知和投递结果。

邮件使用 STARTTLS。Webhook 使用 JSON POST，可选 Bearer 凭据。更换目标地址、SMTP 服务器或邮箱账号时需要重新填写对应凭据；服务端不会把完整凭据返回到页面。

通知配置继续使用应用原有的私有数据目录，升级不会删除已保存的邮件设置。通知后台每 5 秒检查一次新告警，每个事件最多投递 4 次；失败会显示在投递记录中。

发送测试通知只使用当前已保存设置，不会生成硬件动作。远端地址会做协议、主机和实际连接地址检查，拒绝回环、链路本地和保留网络地址。

控制台的普通告警记录、邮件设置和 Webhook 设置可以单独使用。禁用外部通知不会清空本机告警记录。
