fnOS-S2 v1.0.1 保留原控制台的导航、卡片位置和样式，加入 15 项运维功能，并修复认证、跨站请求与权限代理问题。

## 安装与入口

下载本页附件 `fnOS-S2-v1.0.1.fpk`，在飞牛 fnOS 应用中心手动安装或升级。
原控制台地址不变；新功能在相同地址的 `/manage.html`，沿用原主题。
例如：`http://设备地址:18899/manage.html`。请先在同一标签页登录。

## 新增功能

1. 配置备份、下载、导入与恢复前差异预览。
2. 持久化历史监控、趋势图、保留期限和 CSV 导出。
3. 邮件 / Webhook 告警，去重、重试与投递记录。
4. 操作审计，按账号和动作筛选及导出。
5. 每周开关机计划、跳过日期、设备时区和下次执行预览。
6. 可下载的 JSON 设备健康报告。
7. 传感器、RTC、服务与配置诊断，以及受控服务修复。
8. CPU / 磁盘超温和 CPU 传感器失效时的风扇全速保护。
9. 配置版本历史、差异和回退。
10. 脚本内容 / SHA256 审查、变化检查、超时、取消、日志上限和重复运行限制。
11. 限时维护模式，到期恢复，保留风扇保护和温度 / 磁盘告警。
12. 只读、操作员、管理员账号及服务端权限检查。
13. 按权限签发、可过期和撤销的 API 密钥。
14. 多设备只读状态与告警汇总。
15. SMART 历史和变化趋势。

## 修复与兼容说明

- 使用短期会话认证，支持退出和会话失效；不再接受 Cookie 中的原口令或 `?token=` 链接作为认证。
- 写接口检查来源与请求标记；未配置访问口令时，远程访问仅允许读取。
- 可选 root 硬件代理加入私有密钥认证；配置文件使用原子写入和私有权限。
- 修复前端请求超时、失败后控件恢复和设备时区倒计时问题。
- 修复定时计划应用失败未正确反馈，以及升级后已有定时器被关闭的问题。
- 原访问口令登录时，账号留空；创建的账号在登录页填写账号及密码。
- 新增自动策略默认关闭。周计划和风扇保护需要新版硬件组件；升级沿用已有部署流程。
