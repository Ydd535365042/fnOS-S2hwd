# fnOS-S2 v1.0.7

本版恢复脚本库的默认脚本，加入风扇滑动调速，修好邮件通知，并集中处理界面迟钝和状态不一致的问题。

## 脚本库

- 六个默认脚本回到脚本库：硬件自检、收集诊断信息、升级 S2 设备树、安装 / 停用电源灯美化、回滚上次 DTB 升级。升级应用时自动补回，已有的同名脚本和自定义脚本不会被覆盖。
- 脚本库右上角新增「恢复默认脚本」，误删后一键补回。
- 执行日志新增「停止」，可终止正在运行的脚本；刷新或重新打开页面后会自动接回还在运行的任务。运行期间点「清空」只清屏，不再丢掉任务。
- 电源灯美化既可以用脚本 30 / 40，也可以用「已安装模块」里的电源灯美化包。两者管理的是同一组服务，请只用其中一种。

## 风扇

- 风扇卡新增「手动转速」滑块（30–100%）。松手后约 2 秒生效，点「恢复自动」或切换静音 / 性能档位即回到温控曲线。
- 手动转速在设备重启后失效；温度到达曲线全速点、传感器失效或超温时仍会自动全速。手动调速需要原生控制（已升级设备树）。
- 卡片正面显示处理器和硬盘两路的当前温度、曲线锚点和需求转速，不再留出大片空白。
- 转速来源说明改为按控制器实际状态显示：手动、保护全速、硬盘温度未知保底、降温回差，不再一律显示「处理器触发」。
- 修改曲线后不保存直接返回，会撤销改动并回到设备实际档位。
- 不再读取旧运维中心留下的风扇保护配置。该配置在 1.0.6 已没有界面，可能把风扇锁在全速且无法关闭。

## 邮件通知

- 新增加密方式：SSL（端口 465）和 STARTTLS（端口 587）。此前只支持 STARTTLS，QQ / 163 等邮箱常用的 465 端口发不出去。
- 「发送测试通知」直接使用当前填写的内容，不必先保存。
- 失败时给出具体原因：授权码错误、端口与加密方式不匹配、发件地址被拒、无法解析服务器、连接超时等。
- 邮件正文改为可读文本（标题、级别、时间、详情、设备名），并补齐日期和邮件编号头，降低被判为垃圾邮件的概率。
- 新邮箱配置未填授权码时保存会直接提示，不再存成一条必然失败的配置。

## 响应速度与稳定性

- 小响应不再等待网络层延迟确认，按钮操作和轮询回包更快。
- 保存定时开关机等慢操作期间，状态刷新不再被阻塞，仪表盘不再停住。
- 写操作后的刷新不再被正在进行的刷新吞掉，按钮不会回跳到旧状态。
- 服务状态查询按服务缓存并合并并发请求；硬盘休眠状态优先读取控制器已有的记录，不再每次轮询探测每块盘。
- 处理器占用、网速等速率不再因多个页面同时打开而跳动。
- 脚本输出轮询只处理要显示的行，长日志不再每次从头统计。
- 传感器连续读取失败时顶栏显示「连接中断」，不再静默停在旧读数。
- 服务重启失败时如实报告失败。
- 服务器内部错误返回明确提示，不再表现为连接中断。
- 模块安装期间按钮保持禁用；内置模块不再提供会把模块本身删掉的「卸载」。
- 选中硬盘序列号等文字时不会被轮询刷新冲掉。
- 全部硬盘休眠时硬盘温度显示为无读数，不再显示 0 ℃。

## 清理

- 移除旧运维中心遗留的配置备份 / 恢复、维护窗口、风扇保护和诊断接口。

真实 NAS 上的风扇手动调速、邮件投递、DTB 写入与重启仍需实机验证。
