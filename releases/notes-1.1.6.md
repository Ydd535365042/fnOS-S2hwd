# fnOS-S2 v1.1.6

修复实机上发现的两个问题。

## 硬盘没到起转温度，风扇却一直转

- 现象：硬盘 40℃，没到静音曲线的起转点 42℃，风扇却一直按 30% 转。卡片上写着「降温中 · 硬盘降到 40℃ 以下停转」。
- 原因：温控有一个 2℃ 的降温回差。哪一路温度把风扇转起来，等它降到起转点下 2℃ 才停，避免在临界点反复启停。原来的代码只记了「风扇是被温控曲线转起来的」，没有记是哪一路：
  1. 升级应用、跑重任务时 CPU 会短暂超过 60℃，风扇按 CPU 曲线转了起来。
  2. CPU 降温后，代码把回差套在了所有温度来源上。
  3. 硬盘 40℃ 加 2℃ 正好等于硬盘起转点 42℃，于是按「硬盘还在降温」保持 30%。
  4. 硬盘平时就在 40–41℃，降不到 40 以下，风扇就一直被锁着。
- 修复：CPU 和硬盘各自记录自己有没有把风扇转起来，回差只作用在那一路上。
  - CPU 短暂升温后降回去，风扇按 CPU 自己的回差（58℃）停转，不再牵连硬盘。
  - 硬盘真的到过 42℃，回差照常保留，降到 40℃ 以下才停。

## 电源灯美化显示「未运行」

- 「S2 电源灯美化」包含两个服务：开机指示（开机时电源灯闪烁，控制台起来后退出）和关机指示（关机时变橙色、响一声）。它们只在开机或关机时运行，平时停着是正常的。
- 原来模块卡片把开机指示服务标成「未运行」，看起来像坏了。模块重装后，systemd 的运行记录清零，关机指示服务也会被说成「已执行」。
- 现在内置模块声明哪些服务只在开关机时运行，卡片显示「开关机时运行」，鼠标停留时说明原因。真的失败仍显示「失败」。

## 验证

- 风扇控制新增 8 项检查，复现了实机现场：CPU 61℃ 起转后降到 50℃、硬盘 40℃。旧代码保持 30%，并报告「硬盘降温中」；新代码停转。另外确认 CPU 自己的回差，以及硬盘真到过 42℃ 后的回差仍然有效。
- 开关机服务显示新增 7 项检查。
- 实机安装 1.1.6 后测试：
  - 风扇回差的现场复现：四核加负载，CPU 2 秒内升到 61.7℃，风扇按 CPU 曲线起转 30%。撤掉负载后 CPU 回落到 52.5℃，硬盘此时 41℃，风扇立即停转。旧版本在同样情况下会一直保持 30%。
  - 登录、状态读取、模块状态、风扇手动与恢复自动、定时开关机打开与关闭全部通过。
  - 浏览器（桌面与手机）无脚本错误，模块卡片显示「开关机时运行」。
  - 测试后所有配置、定时器、RTC 闹钟、服务启用状态和脚本库都与测试前一致。
- 原有全部回归检查通过。
